### 8.2 一个失败的检查项（已澄清，非阻塞）

`install dir has no runtime __pycache__ or .pyc` **失败**：

- 安装目录里存在 12 个空 `__pycache__\` 目录
- **这 12 个目录是 Inno Setup 在安装时**把 vendored packages（`comtypes\` / `pyJianYingDraft\` / `pymediainfo\` / `uiautomation\`）的目录结构原样打包带过来的，**不是**运行时 embedded Python 创建的
- 验证方法：`Get-ChildItem -Recurse -Filter '__pycache__'` 的 `CreationTime` 全部是 `2026/6/21 16:24:46`（Inno Setup 安装时间戳），而**不是** launcher 启动时间 `16:29:45`
- **运行时 .pyc 文件**（核心问题）数量：**0**（验证 `Get-ChildItem -Recurse -Filter '*.pyc'` 返回 0 个文件）
- **LocalAppData 里**有 87 个 .pyc 文件（`%LOCALAPPDATA%\ShipinCut\cache\pycache\`），证明 `PYTHONPYCACHEPREFIX` 重定向生效
- 结论：安装目录**功能上**是干净的（无运行时字节码），只是**结构上**残留了 vendored 包自带的空 `__pycache__\` 占位目录
- 这是 Inno Setup `Excludes: "__pycache__\*,*.pyc"` 只能排除**文件**不能排除**空目录**的已知限制，**不**属于 4A-2 引入的新问题
- 4A 阶段沿用 3C-4 的 Inno Setup 脚本，**未改动**安装脚本

### 8.3 后续建议（非阻塞）

如果 4B 或 5A 阶段要彻底清理安装目录的 `__pycache__\` 目录，可以在 Inno Setup 里加：

```
[InstallDelete]
Type: filesandordirs; Name: "{app}\__pycache__"
```

或者在 `[Files]` 段之前/之后加 `[UninstallDelete]` 段。本轮**不**做（避免改动 Inno Setup 脚本触发额外回归）。
