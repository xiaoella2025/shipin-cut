# 视频混剪工具安装包雏形说明

## 阶段定位

本文对应**阶段 3A + 3B**。

- 阶段 1 已完成：打开草稿文件夹、尝试打开剪映。
- 阶段 2 已完成：Windows 本地启动器。
- 阶段 3A 已完成：Inno Setup 脚本、桌面/开始菜单快捷方式和构建入口。
- 阶段 3B（当前）已完成：前端静态化、去掉 Node/npm 运行依赖。
- 阶段 4-6 仍按既有文档推进，本轮不涉及兑换码、后台或自动更新。

3B 不是正式商业安装版，也不承诺在全新无开发环境的 Windows 机器上直接运行——3C 之前仍需 Python。

## 安装内容

安装包把当前开发态运行需要的轻量源码安装到：

```text
{autopf}\ShipinCut
```

主要包含：

- `dist/`（v0.9.13 新增）：由 `vite build` 生成的静态前端，安装版运行时不依赖 Node/npm。
- `package.json` / `src/` / `vite.config.js`：保留作为开发文档，运行时不读取。
- `tools/` + `tools/pyjianying_runtime/` + `tools/jianying_draft/`：Python 后端与剪映草稿导出。
- `launcher/`：Windows 本地启动器。
- `tools/whisper/`、`local-tools/ffmpeg/`（可选）：本机构建机上存在才被打包；缺则启动时给出明确提示。
- `启动视频混剪工具.bat`：桌面图标入口。

明确不包含：

- `.git/`、日志和本地个人配置。
- `export_workspace/`、输入素材、导出视频、剪映草稿和测试样本。
- `node_modules/`：安装版运行已不需要它，3B 起不再打包。
- Python runtime、ffmpeg、whisper-cli、模型文件。
- `tmp/pyjianying_probe` 本地虚拟环境。

## 当前依赖条件

目标机器目前仍需：

1. Python 可在命令行中运行。
2. 若要使用字幕识别、视频处理和剪映草稿导出，还需按当前开发环境准备 ffmpeg、whisper-cli、模型和 pyJianYingDraft 运行环境。

**不再依赖 Node/npm。**安装版运行时由 Python 后端托管 `dist/` 静态资源，不再启动 Vite dev server、不再占用 5173 端口。开发态如果要在本地改前端并实时预览，可以继续 `npm run dev`，此时 Vite 会用 5173，与安装版互不干扰。

## 如何编译

1. 安装 Inno Setup 6。
2. 在仓库根目录运行：

```bat
npm.cmd run build
installer\build-installer.bat
```

3. 成功后得到：

```text
installer\dist\ShipinCutSetup.exe
```

如果未检测到 Inno Setup，构建脚本会提示：

```text
未找到 Inno Setup，请先安装 Inno Setup 6
```

构建脚本目前不会自动调用 `npm build`；必须先手动构建 `dist/`，否则启动器会报”前端构建产物缺失”。

## 如何安装和启动

1. 双击 `ShipinCutSetup.exe`。
2. 默认安装到 `{autopf}\ShipinCut`，也可以在向导中选择含空格或中文的其他目录。
3. 安装向导创建开始菜单入口，并可选择创建桌面”视频混剪工具”快捷方式。
4. 安装完成页可勾选立即启动。
5. 快捷方式直接指向 `{app}\启动视频混剪工具.bat`，working directory 为 `{app}`。

启动后由阶段 2 启动器完成：检测 `{app}\dist\index.html` 进入静态前端模式 → 启动 `tools\local_export_server.py`（8765）→ 自动打开 `http://127.0.0.1:8765/shipin-cut/`。开发态在仓库根目录运行 `启动视频混剪工具.bat` 时若 `{app}\dist\index.html` 不存在，会回退到 Vite dev 模式（5173）。

## 卸载

Inno Setup 自动生成卸载入口。卸载会移除安装文件、开始菜单快捷方式和桌面快捷方式。安装目录 `{app}` 只存放程序文件；日志、启动锁和运行状态、用户配置、缓存以及导出工作区分别写入 `%LOCALAPPDATA%\ShipinCut\logs\launcher`、`%LOCALAPPDATA%\ShipinCut\runtime`、`%LOCALAPPDATA%\ShipinCut\config`、`%LOCALAPPDATA%\ShipinCut\cache` 和 `%LOCALAPPDATA%\ShipinCut\workspace`。这些用户数据目录在卸载时保留，后续可单独提供清理选项。

## 当前限制

- 仍依赖本机 Python（3C 内置）。
- 未内置 ffmpeg、whisper-cli 和模型文件（构建机可选打入；缺时启动器仍能跑起来，但字幕识别/视频处理会报错）。
- 未打包 pyJianYingDraft Python 运行环境（3B 已改为 `tools/pyjianying_runtime/` 直接随安装包，依赖项仍按运行环境准备）。
- 未做兑换码入口或后台。
- 未做检查更新或自动更新。
- 未配置正式应用图标和代码签名。
