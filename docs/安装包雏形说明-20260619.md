# 视频混剪工具安装包雏形说明

## 阶段定位

本文对应**阶段 3A：Inno Setup 安装包雏形**。

- 阶段 1 已完成：打开草稿文件夹、尝试打开剪映。
- 阶段 2 已完成：Windows 本地启动器。
- 阶段 3A 本轮完成：Inno Setup 脚本、桌面/开始菜单快捷方式和构建入口。
- 阶段 4-6 仍按既有文档推进，本轮不涉及兑换码、后台或自动更新。

3A 不是正式商业安装版，也不承诺在全新无开发环境的 Windows 机器上直接运行。

## 安装内容

安装包把当前开发态运行需要的轻量源码安装到：

```text
{autopf}\ShipinCut
```

主要包含：

- Vite/React 前端源码与配置。
- 前端运行所需的 `node_modules`，作为安装目录中的只读程序依赖。
- Python 本地服务和剪映草稿相关脚本。
- Windows 本地启动器。
- `启动视频混剪工具.bat`。
- 必要使用和阶段说明文档。

明确不包含：

- `.git/`、日志和本地个人配置。
- `export_workspace/`、输入素材、导出视频、剪映草稿和测试样本。
- Python runtime、ffmpeg、whisper-cli、模型文件。
- `tmp/pyjianying_probe` 本地虚拟环境。

## 当前依赖条件

目标机器目前仍需：

1. Python 可在命令行中运行。
2. Node/npm 可在命令行中运行。
3. 若要使用字幕识别、视频处理和剪映草稿导出，还需按当前开发环境准备 ffmpeg、whisper-cli、模型和 pyJianYingDraft 运行环境。

缺少 Python 或 Node/npm 时，阶段 2 启动器会显示中文提示，不会静默失败。`node_modules` 由安装包写入，普通用户无需在 Program Files 下运行 `npm install`。

## 如何编译

1. 安装 Inno Setup 6。
2. 在仓库根目录运行：

```bat
installer\build-installer.bat
```

3. 成功后得到：

```text
installer\dist\ShipinCutSetup.exe
```

如果未检测到 Inno Setup，构建脚本会提示：

```text
未找到 Inno Setup，请先安装 Inno Setup 6
```

## 如何安装和启动

1. 双击 `ShipinCutSetup.exe`。
2. 默认安装到 `{autopf}\ShipinCut`，也可以在向导中选择含空格或中文的其他目录。
3. 安装向导创建开始菜单入口，并可选择创建桌面“视频混剪工具”快捷方式。
4. 安装完成页可勾选立即启动。
5. 快捷方式直接指向 `{app}\启动视频混剪工具.bat`，working directory 为 `{app}`。

启动后仍由阶段 2 启动器完成：检测/复用 8765 后端、检测/复用 5173 前端、自动打开 `http://localhost:5173/shipin-cut/`。

## 卸载

Inno Setup 自动生成卸载入口。卸载会移除安装文件、开始菜单快捷方式和桌面快捷方式。安装目录 `{app}` 只存放程序文件；日志、启动锁和运行状态、用户配置、缓存以及导出工作区分别写入 `%LOCALAPPDATA%\ShipinCut\logs\launcher`、`%LOCALAPPDATA%\ShipinCut\runtime`、`%LOCALAPPDATA%\ShipinCut\config`、`%LOCALAPPDATA%\ShipinCut\cache` 和 `%LOCALAPPDATA%\ShipinCut\workspace`。这些用户数据目录在卸载时保留，后续可单独提供清理选项。

## 当前限制

- 仍依赖本机 Python。
- 仍依赖本机 Node/npm，但前端依赖已经随安装包提供。
- 未内置 ffmpeg、whisper-cli 和模型文件。
- 未打包 pyJianYingDraft Python 环境。
- 未做兑换码入口或后台。
- 未做检查更新或自动更新。
- 未配置正式应用图标和代码签名。
