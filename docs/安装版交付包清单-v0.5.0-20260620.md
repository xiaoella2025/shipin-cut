## 1. 给用户的最终文件

只需要一个文件：

```
installer\dist\ShipinCutSetup.exe
```

- 体积：198,257,888 字节 ≈ 189 MB
- MD5 / SHA256：构建时记录（建议在交付包旁附 `.sha256` 文本文件）

把它发给用户 / 学员就行。

## 2. 用户**不需要**安装

> 装好的 v0.5.0 安装版**自带**以下所有运行时，**用户电脑不需要预先安装这些**。

- ❌ **不需要** Node.js
- ❌ **不需要** npm
- ❌ **不需要** Python（系统 Python / py launcher 都不需要）
- ❌ **不需要** ffmpeg
- ❌ **不需要** whisper-cli / ggml-base.bin 模型
- ❌ **不需要** Git
- ❌ **不需要** VS Code / 任何开发工具
- ❌ **不需要** Microsoft Visual C++ Redistributable（embedded Python 自带必要的运行库）

## 3. 用户电脑**需要已有**

- ✅ **Windows 10 / 11**（x64）
- ✅ **剪映专业版**（如果用户要打开导出的剪映草稿做最终调整；如果只用工具做字幕识别 / 切片，不装剪映也行）
- ✅ **足够磁盘空间**：安装后约 600 MB（embedded Python 20 MB + whisper 模型 ~140 MB + ffmpeg ~150 MB + pyJianYingDraft 站点包 + 后端 + 前端 dist + 文档）
- ✅ **管理员权限**（安装时 Inno Setup 要求 admin，写 `C:\Program Files\ShipinCut` 或用户选的其他目录）
- ✅ **8765 端口空闲**（不要被别的程序占用）

## 4. 用户安装步骤

1. 双击 `ShipinCutSetup.exe`（如果 Windows SmartScreen 提示，选择"仍要运行"）
2. 安装向导一步步"下一步"，可在"选择安装位置"那一步改目录（默认 `C:\Program Files\ShipinCut`，含空格 / 中文都行）
3. 桌面出现"**视频混剪工具**"快捷方式，开始菜单也有
4. 勾选"安装完成后启动"或自己双击桌面图标
5. 启动后**浏览器自动打开** `http://127.0.0.1:8765/shipin-cut/`

> **首次启动稍慢**（5–10 秒）：embedded Python 首次加载要编译部分 `.pyc` 到 `%LOCALAPPDATA%\ShipinCut\cache\pycache\`。第二次启动就快了。

## 5. 用户使用前自检

打开页面后，建议按以下顺序自检一遍：

- [ ] **页面是否打开**：`http://127.0.0.1:8765/shipin-cut/` 能看到工具主页
- [ ] **是否显示 8765**：地址栏必须是 8765（**不是** 5173）
- [ ] **上传一段小视频**（建议 30 秒内、含清晰人声）
- [ ] **点击"字幕识别"**：等几秒，字幕分段出来
- [ ] **导出剪映草稿**：在工具里点"导出"，成功后浏览器 / 系统会给出"打开草稿文件夹"提示
- [ ] **打开剪映**：剪映 → 我的草稿 → 找到刚导出的草稿 → 拖到时间线检查字幕是否对得上

如果以上都通过，工具就可以正常用了。

## 6. 常见问题

### Q：打不开页面怎么办？

A：先关掉黑窗口和浏览器，重新点桌面图标；如仍不行，看日志：
- 启动器日志：`%LOCALAPPDATA%\ShipinCut\logs\launcher\launcher_<date>.log`
- 后端日志：`%LOCALAPPDATA%\ShipinCut\logs\backend\...`
看 ERROR 行贴出来给助理。

### Q：为什么是 8765，不是 5173？

A：3B 起前端已经静态化，安装版由 Python 后端（8765）直接托管 `dist/`，**不再依赖 Vite dev server**。开发态如果要在本地改前端实时预览，可以单独跑 `npm run dev`（5173），与安装版互不干扰。

### Q：需要安装 Python 吗？

A：**不需要**。v0.5.0 安装包自带 Python 3.11.9（embedded 发行版），位于安装目录下的 `runtime\python\python.exe`，启动器优先用它。

### Q：需要安装 Node 吗？

A：**不需要**。

### Q：需要安装 ffmpeg 吗？

A：**不需要**。v0.5.0 安装包自带 ffmpeg / ffprobe，位于 `local-tools\ffmpeg\`，启动器优先调用它；只有当用户手动删了 `local-tools\ffmpeg` 才会回退到系统 PATH。

### Q：需要安装 whisper 吗？

A：**不需要**。v0.5.0 安装包自带 `tools\whisper\whisper-cli.exe` 和 `tools\whisper\models\ggml-base.bin`。

### Q：为什么需要剪映？

A：本工具**不是**剪映的替代品，**只负责**素材导入 / 字幕识别 / 切片 / 组合方案 / 基础调整 / 导出剪映草稿。**字幕样式 / 贴纸 / 音乐 / 关键帧 / 滤镜 / 最终导出发布** 仍然在剪映里完成。

### Q：运行数据 / 草稿 / 日志在哪里？

A：全部在 `%LOCALAPPDATA%\ShipinCut\` 下：

- `logs\launcher\`：启动器日志
- `logs\backend\`：后端日志
- `runtime\`：运行期状态 / 锁文件
- `config\`：用户配置（**未来**兑换码激活状态会写在这里）
- `cache\pycache\`：embedded Python 的 `.pyc` 缓存
- `workspace\videos\`：用户上传的视频
- `workspace\temp\`：处理中临时文件
- `workspace\output\`：处理后的视频片段
- `workspace\drafts\`：导出的剪映草稿中间产物

**安装目录（`C:\Program Files\ShipinCut` 或用户选的位置）只放程序文件，运行时不会写它。**

### Q：可以装在 D 盘 / 中文目录 / 含空格的目录吗？

A：可以。Inno Setup 用 list 形式调用 `subprocess`，所有路径都做了 quote。**不**要装到 OneDrive / 网盘同步目录下，会出 IO 性能 + 权限问题。

### Q：可以覆盖安装 / 升级吗？

A：当前 v0.5.0 的覆盖安装已验证 OK（3C-4 跑过）。后续做自动更新时，会先关后端再覆盖 `{app}\runtime\python\`（约 20 MB），不要在运行时直接覆盖。

### Q：可以卸载吗？

A：可以。控制面板 → 程序和功能 → 视频混剪工具 → 卸载。**注意**：卸载会保留 `%LOCALAPPDATA%\ShipinCut\`（用户数据 / 草稿 / 缓存），如要彻底清理请手动删除。

### Q：可以离线用吗？

A：可以。v0.5.0 完全离线运行，**不**做远程校验 / 心跳 / 自动更新（这些会在后续 4A / 5A 阶段加入）。

### Q：杀毒软件报毒怎么办？

A：v0.5.0 在本机 Windows Defender 默认策略下能直接放行。**未做**主流杀软（360 / 火绒 / 卡巴斯基）的长期观察，遇到误报请把安装包提交给对应厂商做白名单申请。后续做安装包签名（Authenticode）会降低误报概率。

## 7. 给助理 / 学员的注意事项

> 下面是**不要做**的事，列出来避免误操作破坏安装版。

- ❌ **不要删除** `runtime\python\`（embedded Python，启动器优先用它）
- ❌ **不要删除** `tools\whisper\`（whisper-cli + ggml-base.bin，字幕识别依赖）
- ❌ **不要删除** `local-tools\ffmpeg\`（ffmpeg / ffprobe，视频处理依赖）
- ❌ **不要删除** `tools\pyjianying_runtime\`（pyJianYingDraft + pymediainfo + uiautomation + comtypes，剪映草稿导出依赖）
- ❌ **不要移动安装目录内文件**（启动器按 `{app}` 绝对路径解析）
- ❌ **不要在安装目录下手动写日志 / 配置 / 缓存**（应该写 `%LOCALAPPDATA%\ShipinCut\`）
- ❌ **不要把安装目录放在 OneDrive / 网盘同步目录**
- ❌ **不要直接覆盖 `runtime\python\python.exe`**（Python 进程运行时锁住它，强制覆盖会失败）
- ❌ **不要装多份安装版到不同目录**（`{app}\runtime\python\` 路径会被写进 bat 硬编码的相对路径，如果改目录要用控制面板卸载干净再装）

如果**误删**了：

- 重新跑一次 `ShipinCutSetup.exe`（Inno Setup 会做覆盖安装，把缺失的文件补回来）
- 安装目录的所有运行时写入（`__pycache__` / `.pyc`）都在 `%LOCALAPPDATA%\ShipinCut\cache\pycache\`，**不会**被覆盖安装清掉

## 9. 给开发 / 助理的内幕备注（**不**给用户看）

> 下面这节是写给开发 / 助理的，**用户不需要知道**这些。

- 安装包 `installer\dist\ShipinCutSetup.exe` 由 `installer\build-installer.bat` 调 Inno Setup 6 编译 `installer\shipin-cut.iss` 生成
- 构建前要确保 `dist/` 是最新的（`npm.cmd run build`），否则启动器会报"前端构建产物缺失"
- 构建前要确保 `installer\runtime\python\` 有内容（embedded Python 3.11.9 64-bit），`installer\tools\pyjianying_runtime\` 也有内容
- `tools\whisper\whisper-cli.exe` / `tools\whisper\models\ggml-base.bin` 是构建机本地存在的（不在仓库里），缺失会回退到系统 PATH 上的同名工具
- `D:\ffmpeg\bin\ffmpeg.exe` / `ffprobe.exe` 是构建机本地存在的，缺失会回退到系统 PATH
- Inno Setup `skipifsourcedoesntexist` 让 ffmpeg / whisper / 草稿模板 / docs 里的部分文件可以缺失而不破编译；但 `installer\runtime\python\*` 缺了**会让安装版启动后立刻报错**——这一项是 v0.5.0 起的强制依赖
- 当前没有自动重打 `ShipinCutSetup.exe` 的 hook；改 `installer\shipin-cut.iss` 后要手动跑 `installer\build-installer.bat`
- 后续做 4A 兑换码入口时，**不要**改 `{app}\launcher\ShipinCutLauncher.py` 入口链路；兑换码 UI 在 `src/App.jsx` 加，状态在 `tools\local_export_server.py` 加 `/activation` 端点，本地写 `%LOCALAPPDATA%\ShipinCut\config\activation.json`
- 后续做 5A 自动更新时，要先做"运行时关闭后端 → 覆盖 `{app}` → 重新启动" 的原子操作，**不要**在用户使用过程中直接覆盖
- 后续做 3C-5B Windows 沙盒测试时，建议用本机 `Windows Sandbox`（开启后能每次给一个干净 Win 实例），不需要装 VMware / VirtualBox
