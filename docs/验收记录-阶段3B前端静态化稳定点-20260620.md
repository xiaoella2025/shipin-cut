## 关键变化

- 安装版不再启动 `npm run dev`。
- 安装版不再使用 5173 Vite dev server。
- 安装包自带 `dist/`（由 `vite build` 生成）。
- 后端 8765 直接托管 `dist/` 静态资源，前缀 `/shipin-cut/`。
- 桌面图标打开 `http://127.0.0.1:8765/shipin-cut/`。
- 安装版运行不再需要 Node / npm。
- `node_modules/` 不再作为运行必需（开发态仍可保留）。
- Inno Setup 打包时不再要求 `node_modules/`，保留 `package.json` / `src/` / `vite.config.js` 仅作开发文档。
