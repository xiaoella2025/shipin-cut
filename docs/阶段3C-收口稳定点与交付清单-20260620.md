## 7. 当前功能边界

- 素材导入（视频文件上传到 `workspace\videos\`）

- 字幕样式（字体 / 颜色 / 描边 / 气泡 / 动画）
- 贴纸
- 音乐 / 音效
- 滤镜 / 转场
- 关键帧动画 / 细节微调
- 最终导出（1080p / 4K / 竖屏 / 横屏 / 帧率 等）
- 发布到抖音 / 视频号 / B站 等平台
