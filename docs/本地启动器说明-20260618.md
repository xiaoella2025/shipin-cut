# 视频混剪工具本地启动器说明

## 阶段定位

本文对应安装版路线的**阶段 2：Windows 本地启动器**。

- 阶段 1 已完成：打开草稿文件夹、尝试打开剪映。
- 阶段 2 本轮完成：双击入口自动启动本地后端和 Vite 前端，并打开浏览器。
- 阶段 3 后续实施：使用 Inno Setup 制作安装包和桌面快捷方式。

本阶段不是正式安装包，不包含兑换码后台、自动更新、Electron 或 Tauri。

## 如何启动

在项目根目录双击：

`启动视频混剪工具.bat`

启动器会依次：

1. 从自身所在目录反推项目根目录，不依赖 `F:\shipin-cut`。
2. 检查 Python、Node/npm 和 `node_modules`。
3. 检查 `127.0.0.1:8765`。
4. 如果检测到 shipin-cut 后端则复用，否则启动 `tools/local_export_server.py`。
5. 检查 `127.0.0.1:5173`。
6. 如果检测到 shipin-cut 前端则复用，否则启动 Vite。
7. 自动打开 `http://localhost:5173/shipin-cut/`。
8. 在启动窗口中持续显示运行状态。

连续双击时，启动器使用本地单实例锁和端口身份探测，避免在服务启动间隙创建多个后端进程。启动器不会执行 `taskkill python.exe` 或 `taskkill node.exe`，也不会误杀其他项目的 Python/Node 进程。

## 日志

日志保存在项目根目录：

```text
logs/launcher/launcher_YYYYMMDD.log
logs/launcher/services_YYYYMMDD.log
```

`launcher_*.log` 记录启动器状态和中文错误；`services_*.log` 记录后端和 Vite 输出。`logs/` 已加入 Git 忽略规则，不会提交本地日志。

## 关闭行为

请在使用期间保持启动窗口打开。

- 关闭浏览器标签页不会主动停止服务。
- 在启动窗口按 `Ctrl+C`，启动器只会停止由本次启动器拉起的子进程。
- 对启动前已经存在并被复用的后端/前端，启动器不会终止。

这能避免误杀用户机器上的其他 Python/Node 进程，也避免中断不属于本次启动器的服务。

## 常见问题

### 页面没有自动打开

手动访问：

`http://localhost:5173/shipin-cut/`

如果仍打不开，请查看 `logs/launcher/` 下当天日志。

### 提示 8765 或 5173 端口被占用

启动器会验证端口上的服务是否属于 shipin-cut。若不是，会停止启动并显示中文提示。请关闭占用对应端口的程序后重试，不要批量结束所有 Python 或 Node 进程。

### 提示 Python 不存在

当前阶段仍依赖本机 Python。请联系管理员安装运行环境。阶段 3 的正式交付版应使用 PyInstaller 或内置 Python runtime，避免要求普通用户自行安装。

### 提示 Node/npm 不存在或缺少 node_modules

当前阶段仍依赖本机 Node/npm 和已安装的前端依赖。请联系管理员处理，不建议启动器静默执行大规模依赖安装。

### 启动后窗口能不能关闭

当前阶段请保持窗口打开。窗口提供运行状态和错误信息；按 `Ctrl+C` 可安全停止本启动器创建的服务。

## 阶段 3 衔接

后续 Inno Setup 安装包会创建桌面快捷方式并指向打包后的启动器。正式交付版还需要处理：

- 使用前端 build 静态资源，避免依赖 Vite 开发服务。
- 使用 PyInstaller 或内置 Python runtime。
- 内置 ffmpeg、whisper-cli 和模型文件。
- 将用户数据和日志迁移到 `%LOCALAPPDATA%\ShipinCut`。

这些属于阶段 3 及后续工作，本阶段不实现。
