## 7. 给填写人的提示

### 7.1 字段填法

- **□ 是 / □ 否**：在对应方框里打勾（用 ✅ 符号也行）
- **____**：直接填文字；如果没看到这字段就填"未测"或"未知"
- **错误信息**：粘贴完整的报错文本（**不**要只写"出错"）
- **路径**：填**完整路径**（如 `C:\Program Files\ShipinCut\`，不要缩写）

### 7.2 截图要求

- **黑窗口截图**：要看到**完整黑窗口**（包括标题栏 + 路径），**不**要只截最后一行
- **页面截图**：要看到**完整页面**（包括地址栏），**不**要只截中间
- **报错截图**：要看到**完整弹窗**（包括按钮）

### 7.3 日志收集

```powershell
# 复制最新启动器日志
Get-Content "$env:LOCALAPPDATA\ShipinCut\logs\launcher\launcher_$(Get-Date -Format 'yyyyMMdd').log" -Tail 50

# 复制最新后端日志
Get-ChildItem "$env:LOCALAPPDATA\ShipinCut\logs\backend\" -Filter '*.log' | Sort-Object LastWriteTime -Descending | Select-Object -First 1 | Get-Content -Tail 50

# 任务管理器里 python.exe 的路径
Get-Process -Name python -ErrorAction SilentlyContinue | Select-Object Id, Path | Format-Table -AutoSize
```

把以上输出**整段复制**到反馈模板里，**不**要只截屏。

### 7.4 如果改不动某项

- 比如 `__pycache__\` 不知道怎么找 → 填"未测"
- 比如没法装 PowerShell → 填"未测，用 cmd 替代"
- 比如剪映没装 → "剪映测试"那几项填"未测（没装剪映）"
- **不**要强行去测每一项；测试的本质是"覆盖到"，**不**是"每项必测"
